Vice Royale is an offline cover art studio built around the Tiled-Gold Ensemble: six cast portraits, gold panel borders, and a sunset palette. Compose with nine layouts and eight color grades, then export PNGs in three sizes: 1920 × 1080, 1080 × 1350, and 1080 × 1080.

Run `node serve.ts` with Node 22 and open http://localhost:8080.
